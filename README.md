# BCaBA Study Guide

Two study tools for the BCaBA exam and ABA coursework, built on Cooper, Heron & Heward, *Applied Behavior Analysis* (3rd ed.):

- `exam.html`: BCaBA Exam Prep, organized by the BCaBA Test Content Outline (6th ed.).
- `classes.html`: Cooper Class Companion, organized by the book's chapters.

All study content is original writing that points to page numbers in the book; no book text is included. The pages are built by a private build script; edit the source there, not these files.
